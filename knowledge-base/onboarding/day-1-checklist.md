# Day 1 Checklist — New Developer Onboarding

## Welcome to the Team

Welcome to TechCorp Engineering! This checklist ensures you have everything set up on your first day.

## Before You Start

- [ ] Confirm your laptop has been shipped (check with IT Asset Management: it-assets@techcorp.com)
- [ ] Verify your @techcorp.com email is active — try signing in at outlook.office.com
- [ ] Join the #new-joiners Slack channel for real-time support

## Morning (9:00 AM - 12:00 PM)

### 1. Security & Access (9:00 - 10:00)
- Sign into your laptop using your Active Directory credentials
- Set up Multi-Factor Authentication (MFA) via Microsoft Authenticator app
- Enroll in Windows Hello for biometric login
- Verify VPN access — connect to `vpn.techcorp.internal` (see VPN Access Guide)

### 2. Development Environment (10:00 - 11:30)
- Install required tools (see Development Environment Setup guide)
- Clone the team repository from GitHub Enterprise: `github.techcorp.com`
- Verify you can build and run the project locally
- Set up your IDE (VS Code or IntelliJ — team preference varies)

### 3. Meet Your Team (11:30 - 12:00)
- Your manager will introduce you in the daily standup
- You'll be assigned an onboarding buddy from the team
- Calendar invite for "Onboarding Kickoff" should already be in your Outlook

## Afternoon (1:00 PM - 5:00 PM)

### 4. Systems Access Verification (1:00 - 2:00)
- Verify access to all systems listed in your Access Provisioning ticket
- If any access is pending, check the status in ServiceNow: `servicenow.techcorp.com`
- Escalate any blockers to your manager or the IT Helpdesk (#it-helpdesk on Slack)

### 5. Read Key Documentation (2:00 - 4:00)
- Review your personalised learning path (provided by the Onboarding Buddy)
- Start with Team Norms and Communication Channels documents
- Bookmark the Architecture Overview for Day 2 reading

### 6. End of Day (4:00 - 5:00)
- Complete the Day 1 Feedback Survey (link sent to your email)
- Note any blockers or missing access for tomorrow's standup
- Your onboarding buddy will check in before end of day
