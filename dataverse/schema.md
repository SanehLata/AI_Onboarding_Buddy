# Dataverse Schema

## Table 1: Developer Profile

| Column | Type | Required | Notes |
|--------|------|----------|-------|
| Full Name | Text (100) | Yes | Primary column |
| Email | Text (200) | Yes | |
| Team | Choice | Yes | Payments, Risk & Compliance, Platform Engineering, Data & Analytics |
| Role | Text (100) | Yes | e.g. Backend Engineer |
| Experience Level | Choice | Yes | Junior / Mid / Senior |
| Manager Email | Text (200) | Yes | Used for Graph API lookups |
| Graph User ID | Text (100) | No | Populated by Graph API lookup |
| Onboarding Status | Choice | Yes | In Progress / Complete |
| Cosmos Session ID | Text (100) | No | Links to Cosmos DB thread |

## Table 2: Access Request

| Column | Type | Required | Notes |
|--------|------|----------|-------|
| Request Name | Text (200) | Yes | Primary column (auto-generated) |
| Developer | Lookup | Yes | FK to Developer Profile |
| System Name | Text (100) | Yes | e.g. GitHub, Jenkins, AWS |
| Request Type | Choice | Yes | Jira Ticket / DL Subscription / AD Group |
| Status | Choice | Yes | Pending / Approved / Rejected |
| Ticket ID | Text (50) | No | Auto-generated TKT-XXXXX |

## Table 3: Learning Path Item

| Column | Type | Required | Notes |
|--------|------|----------|-------|
| Document Title | Text (200) | Yes | Primary column |
| Developer | Lookup | Yes | FK to Developer Profile |
| Sequence | Whole Number | Yes | Reading order (1, 2, 3...) |
| Category | Choice | Yes | Onboarding / Architecture / Runbooks |
| Status | Choice | Yes | Not Started / In Progress / Complete |
| Relevance Reason | Multi-line Text | No | Generated by Foundry agent |

## Table 4: Team Configuration (reference data — pre-populate)

| Column | Type | Required | Notes |
|--------|------|----------|-------|
| Team Name | Text (100) | Yes | Primary column |
| Required Systems | Multi-line Text | Yes | Comma-separated: GitHub, Jenkins, AWS |
| Required Skills | Multi-line Text | Yes | Comma-separated: Python, SQL, Docker |
| DL Groups | Multi-line Text | Yes | Distribution lists |
| AD Groups | Multi-line Text | Yes | Active Directory groups |
| Manager Email | Text (200) | Yes | Default team manager |

## Table 5: Agent Action Log (audit trail)

| Column | Type | Required | Notes |
|--------|------|----------|-------|
| Action Name | Text (200) | Yes | Primary column |
| Developer | Lookup | Yes | FK to Developer Profile |
| Action Type | Choice | Yes | PROFILE_CREATED / TICKET_RAISED / EMAIL_SENT / PATH_GENERATED / APPROVAL_SENT / DOC_COMPLETED |
| Status | Choice | Yes | Success / Failed |
| Details | Multi-line Text | No | JSON payload or error message |
| Cosmos Thread ID | Text (100) | No | Cross-reference to Cosmos DB |
